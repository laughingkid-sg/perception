# Perception apps

This repository contains three applications managed through one npm workspace:

- `housing-affordability-calculator`
- `trading-course`
- `us-compensation-compare`

## Requirements

- Node.js 26.0.0 or newer
- npm 10 or newer

## Install

Install all dependencies once from the repository root:

```bash
npm install
```

## Development

```bash
npm run dev:housing
npm run dev:trading
npm run dev:compensation
```

## Validation

```bash
npm run build
npm run test
npm run typecheck
npm run lint
```
