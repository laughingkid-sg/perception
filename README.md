# Perception apps

This repository contains two React applications managed through one npm workspace:

- `housing-affordability-calculator`
- `us-compensation-compare`

## Requirements

- Node.js 22.13.0 or newer
- npm 10 or newer

## Install

Install all dependencies once from the repository root:

```bash
npm install
```

## Development

```bash
npm run dev:housing
npm run dev:compensation
```

## Validation

```bash
npm run build
npm run test
npm run typecheck
npm run lint
```
